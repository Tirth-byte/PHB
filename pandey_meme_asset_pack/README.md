# Pandey authentic meme template asset pack

This ZIP contains a **download script and a curated manifest**, NOT downloaded image binaries. The remote image host could not be reached from the assistant environment.

## On your Mac
1. Extract ZIP.
2. Open Terminal in the extracted folder.
3. Run `bash download_memes.command`.
4. Copy the resulting `assets/classic/` directory into your website `public/memes/` directory.

36 recognizable original meme template images are linked from Imgflip (not AI parodies). Two requested TV-reaction placeholders are documented but **not included**; do not misrepresent a generic parody as actual The Office footage.

Most template images are copyrighted by their respective owners; check permissions before public deployment. Imgflip hosts templates but does not necessarily own the underlying rights.

Recommended redesign: 1-screen hero + app-like meme viewer with category tabs and lightbox + mini-game + heartfelt finale. Avoid a huge vertical gallery.
